# 老莫聊天室（MoChat）v4.0

> 从“世界喇叭”到全功能跨平台聊天软件的华丽蜕变 🎉

---

## 📖 简介

**老莫聊天室**最初只是一个命令行下的“世界喇叭”——用户登录后只能向所有人广播消息，无身份、无历史、无隐私。  
如今，它已进化为一个**支持私聊、群聊、离线消息、历史漫游、多端同步、安全认证**的现代化桌面聊天应用。

v4.0 是一次**架构级跃迁**：  
✅ **真实身份系统**：彻底告别“ID混淆”，全程使用真实用户名通信  
✅ **全平台消息同步**：私聊/群聊消息跨设备无缝漫游  
✅ **群组生态闭环**：创建、加入、退出、消息广播一气呵成  
✅ **极致用户体验**：亚克力通知、智能补全、时间格式优化、会话分类管理  
✅ **企业级健壮性**：重复登录踢人、连接异常自动恢复、全局日志追踪  

---

## 🚀 核心特性

### 🔐 安全与身份
- 双重验证登录（用户名/ID + 密码）
- 自动生成10位唯一用户ID，避免冲突
- WebSocket + FastAPI 全链路加密（建议部署 HTTPS/WSS）
- 同一账号多端登录自动踢出旧会话

### 💬 聊天能力
- **私聊**：点对点加密通信，支持 `@用户名` 快速发起
- **群聊**：动态创建群组（ID格式 `G123456789`），成员管理
- **消息漫游**：重新登录后自动同步所有历史消息
- **离线消息**：对方不在线？消息持久化，上线即收

### 🖥️ 用户体验
- PyQt6 图形界面，清爽现代设计
- 登录历史智能补全（支持模糊搜索）
- 消息按会话分类存储，左侧栏一键切换
- 时间显示智能优化：
  - 同日 → `14:30:22`
  - 跨日 → `2025年12月17日 14:30:22`
- 系统通知采用半透明亚克力风格，优雅不打扰

### 🛠️ 开发者友好
- **全函数操作日志**：服务端关键流程 `[LOG]` 标记，调试无忧
- 模块化设计：`server.py` / `client.py` / `chat_ui.py` 职责清晰
- 异步非阻塞通信：`aiohttp` + `websockets` + `qasync`
- SQLite 轻量存储：`users.db` / `messages.db` / `groups.db` 三库分离

## 📦 技术栈

| 类别       | 技术                     |
|------------|--------------------------|
| 后端框架   | FastAPI + Uvicorn        |
| 通信协议   | WebSocket (WSS) + REST   |

## 🚦 快速启动

### 服务端（Linux / Windows / macOS）
```bash
# 进入 server 目录
cd server

# 安装依赖（推荐虚拟环境）
pip install fastapi uvicorn[standard] websockets sqlite3

# 启动服务器（默认监听 0.0.0.0:12345）
python -B server.py
```

### 客户端
```bash
# 进入 client 目录
cd client

# 安装依赖
pip install pyqt6 qasync aiohttp websockets

# 启动客户端
python -B main.py
```

> 💡 首次运行会提示输入服务器 IP 和端口（默认 `127.0.0.1:12345`）

## 🌟 为什么叫“从世界喇叭到聊天软件”？

- **v1.0**：只有“世界频道”，所有人看到同一串滚动消息，像一个公共喇叭。
- **v2.0**：引入私聊/群聊概念，但身份混乱（用ID登录却显示ID，无法私聊）。
- **v3.x**：强化安全与同步，但群组功能缺失，仍像“高级喇叭”。
- **v4.0**：**完整社交图谱**！你可以：
  - 创建技术交流群 `G123456789`
  - 私聊好友 “张三” 讨论周末计划
  - 上班时在 Windows 登录，下班用 Mac 继续对话
  - 所有历史消息按会话归档，清晰可溯

> 这不再是喇叭，而是一个**属于你的数字客厅**。
