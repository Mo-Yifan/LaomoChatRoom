# 老莫聊天室（Laomo Chatroom）

一个基于 FastAPI + WebSocket + PyQt6 的跨平台桌面聊天应用，支持私聊、群聊、离线消息、历史漫游、重复登录踢人等完整功能。

---

## 功能亮点

- **双端架构**：后端使用 FastAPI 提供 REST API 与 WebSocket 服务；前端使用 PyQt6 构建美观的桌面 UI。
- **用户系统**：
  - 注册时自动生成唯一 10 位数字账号 ID（无需记忆用户名）
  - 登录支持 **用户名 或 账号 ID** 双方式
  - 密码明文存储（仅用于演示，生产环境请加密）
- **消息系统**：
  - 实时群聊 & 私聊（`@用户名 消息`）
  - 离线消息自动投递（上线后立即接收）
  - 完整聊天历史漫游（含私聊和群聊）
  - 系统消息显示更美观，尽显高级感
- **安全机制**：
  - 防冒用：WebSocket 连接必须先通过 `login` 认证
  - 重复登录自动踢出旧连接
- **用户体验**：
  - 登录界面支持历史账号自动补全
  - 注册/登录窗口平滑切换
  - 消息按时间格式化显示

## 项目结构

```
老莫聊天室/
├── server.py        # 后端服务（FastAPI + WebSocket + SQLite）
├── client.py        # 客户端网络逻辑（aiohttp + websockets）
├── main.py          # 应用入口（管理 UI 与客户端生命周期）
├── login_ui.py      # 登录窗口（带历史账号补全）
├── register_ui.py   # 注册窗口（密码二次确认）
└── chat_ui.py       # 聊天主界面（支持 @私聊）
```

## 运行说明

> 为避免生成 `__pycache__` 文件夹，请始终使用 `python -B` 命令运行！

### 1. 启动服务器

```bash
python -B server.py
```

默认监听 `0.0.0.0:12345`，启动后将看到：

```
FastAPI 聊天服务器已启动（增强认证版 + 全日志）
正在监听端口: 12345
WebSocket URL: ws://<服务器IP>:12345/ws
客户端连接后，请立即发送：
 {"type":"login","username":"xxx","password":"yyy"}
```

### 2. 启动客户端

```bash
python -B main.py
```

程序会弹出对话框，要求输入 **服务器 IP** 和 **端口**（默认 `12345`）。

- 首次使用 → 点击“没有账号？去注册” → 填写信息注册
- 已有账号 → 输入 **用户名** 或 **10 位账号 ID** + 密码登录

> 注意：注册成功后会显示你的 **10 位账号 ID**，请务必保存！可用于后续登录。

## 测试建议

1. **多开测试**：同一账号在两台设备（或两个窗口）登录，旧连接会被踢下线。
2. **离线测试**：
   - A 用户在线，B 用户离线
   - A 给 B 发私聊 → B 上线后立即收到
3. **历史漫游**：新设备登录后自动加载所有历史消息（包括私聊）。
4. **私聊语法**：在聊天框输入 `@对方用户名 你好` 即可私聊。

## 注意事项

- **数据库**：首次运行自动创建 `users.db`和`message.db`，实现用户数据与消息数据的分流。
- **账号 ID**：注册时系统分配 10 位唯一数字 ID（如 `0827364915`），可替代用户名登录。
- **Windows 兼容**：已适配 Windows asyncio 事件循环策略，无需额外配置。
- **开发模式**：所有函数均有 `[LOG]` 打印，便于调试（生产可移除）。
